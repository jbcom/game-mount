## 0.1.0 candidate

The initial candidate provides a renderer-neutral core, isolated adapters for Pixi, React Three Fiber and Babylon, optional peers, ESM/CommonJS declarations and a host stylesheet. It has not yet been tagged or published.

Release Please manages subsequent version and changelog changes. The CD workflow publishes subsequent releases through npm trusted publishing.

See [Changelog](https://github.com/jbcom/game-mount/blob/main/CHANGELOG.md) and [GitHub releases](https://github.com/jbcom/game-mount/releases) for published release evidence. Candidate documentation does not imply registry availability.
