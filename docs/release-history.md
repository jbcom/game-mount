## Initial release

Version [0.1.0](https://github.com/jbcom/game-mount/releases/tag/v0.1.0) introduced a renderer-neutral core, isolated adapters for Pixi, React Three Fiber and Babylon, optional peers, ESM/CommonJS declarations and a host stylesheet.

Release Please manages version and changelog changes. The CD workflow publishes releases through npm trusted publishing.

See [Changelog](https://github.com/jbcom/game-mount/blob/main/CHANGELOG.md), [GitHub releases](https://github.com/jbcom/game-mount/releases), and [npm](https://www.npmjs.com/package/game-mount) for the current published version and release evidence.
